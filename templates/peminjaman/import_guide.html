Cara Import Excel Peminjaman

  1. Upload file Excel (.xlsx) — boleh file yang sama dengan data Aset, boleh punya banyak sheet
  2. Sistem otomatis mencari sheet yang punya kolom sesuai format di bawah — tidak harus sheet pertama atau baris header pertama
  3. Setiap baris akan ditambahkan sebagai data Peminjaman baru
  4. Nilai kolom Unit otomatis tersimpan sebagai master data baru di halaman Kategori (kalau belum ada)

📋 Format Kolom yang Dicari

Sistem mendeteksi sheet & baris header berdasarkan nama kolom (bukan posisi), jadi urutan kolom di Excel bebas — yang penting nama headernya cocok:

Nama Kolom Excel Disimpan Sebagai Wajib
Nama Nama peminjam Dipakai untuk deteksi sheet
Unit Unit/bagian peminjam — otomatis dibuat sebagai master data Opsional
Lokasi Kerja Lokasi kerja peminjam Opsional
Jenis Barang Teks bebas (mis. Laptop, Handphone) — tidak dihubungkan ke data Aset utama Opsional
Jenis Transaksi Peminjaman / Pengembalian / Pelimpahan IN / Pelimpahan OUT / dll Dipakai untuk deteksi sheet
Tanggal Awal Tanggal mulai pinjam Opsional*
Tanggal Akhir Rencana kembali / tanggal dikembalikan Opsional*
Keterangan Deskripsi bebas Opsional
Evidence Lampiran Link Google Drive (diambil dari hyperlink cell) — ditampilkan sebagai tombol "Lihat PDF" Dipakai untuk deteksi sheet

* Minimal salah satu dari Tanggal Awal/Tanggal Akhir harus terisi — baris yang dua-duanya kosong akan dilewati.

Tips

  • • File boleh sama dengan file import Aset — sheet-nya otomatis ditemukan berdasarkan nama kolom
  • • Link Evidence diambil dari hyperlink yang nempel di cell, bukan dari teks nama filenya
  • • Unit baru otomatis dibuat di halaman Kategori, tidak perlu ditambahkan manual dulu
  • • Baris dengan Jenis Transaksi mengandung kata "Pengembalian" otomatis ditandai status "Dikembalikan"

Peringatan

  • • Jenis Barang tidak dihubungkan ke data Aset — cuma teks catatan
  • • Kalau Tanggal Awal kosong, sistem pakai Tanggal Akhir sebagai tanggal pinjam (perkiraan)
  • • Import ini selalu menambahkan baris baru — belum ada deteksi duplikat, cek data dulu sebelum import ulang
  • • File harus berformat .xlsx (Excel 2007+)
