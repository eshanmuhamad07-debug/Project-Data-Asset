Cara Import Excel

  1. Download file Excel contoh via tombol Download Contoh Excel di bawah
  2. Isi data sesuai dengan kolom yang tersedia (lihat tabel di bawah)
  3. Upload file Excel yang sudah diedit menggunakan form di bagian bawah halaman
  4. Sistem akan otomatis menambahkan data baru dan memperbarui data yang sudah ada

Tips

  • • Export data yang sudah ada → edit → Import kembali untuk update massal
  • • kode_aset digunakan sebagai identifier — jika sama, data akan di-update
  • • Kategori baru akan dibuat otomatis jika belum ada di sistem
  • • Foto dari Google Drive akan otomatis diubah menjadi thumbnail

Peringatan

  • • kode_aset dan nama wajib diisi — baris kosong akan dilewati
  • • Jika tipe_aset kosong, default OPEX
  • • Pastikan format tanggal YYYY-MM-DD (contoh: 2024-01-15)
  • • File harus berformat .xlsx (Excel 2007+)
